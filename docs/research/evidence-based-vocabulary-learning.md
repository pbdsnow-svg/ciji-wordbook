# 个人词汇 PWA 的循证学习逻辑

> 调研日期：2026-08-10
>
> 范围：个人使用、local-first/offline PWA；只讨论学习逻辑，不涉及本轮代码修改。

## 结论先行

没有证据证明某一种背词法对所有人都“最有效”。现有一手研究较一致地支持一个组合：**先清楚编码词形、读音和意义，再进行主动回忆；把回忆分散到多个时间点；答错后给正确反馈；掌握基础词义后，再在不同句子和文章中重新遇到并使用。**

因此，软件不应继续把“每天展示固定数量的新词”当作主循环。主循环应改为：**到期旧词主动回忆 → 错词反馈与本轮重测 → 在容量允许时引入少量新词 → 用拼写和新语境检验能否真正提取。**

## 证据强弱与产品含义

### 1. 主动回忆：强证据，应成为核心

Karpicke 与 Roediger 让大学生学习外语词对。词首次答对后，继续看答案对延迟保持帮助很小；继续回忆测试则明显改善一周后的保持。该研究直接涉及外语词汇，和本产品最接近。[原始论文与作者 PDF](https://learninglab.psych.purdue.edu/downloads/2008/2008_Karpicke_Roediger_Science.pdf)，DOI：[10.1126/science.1152408](https://doi.org/10.1126/science.1152408)。Roediger 与 Karpicke 的另一项短文实验也发现：重复阅读在 5 分钟测试中更好，但在 2 天和 1 周后的保持不如回忆测试。[原始论文](https://doi.org/10.1111/j.1467-9280.2006.01693.x)。

Kang、McDermott 与 Roediger 的实验进一步表明，在提供纠正反馈时，要求生成答案的简答测试在三天后的表现优于选择题和重复阅读。[作者所在机构记录](https://profiles.wustl.edu/en/publications/test-format-and-corrective-feedback-modify-the-effect-of-testing-/)，[作者 PDF](https://psychnet.wustl.edu/memory/wp-content/uploads/2018/04/Kang-et-al-2007_EJCP.pdf)，DOI：[10.1080/09541440601056620](https://doi.org/10.1080/09541440601056620)。

产品含义：

- “看单词—翻卡—觉得认识”不能计为掌握。
- 核心题型应要求从中文、语音、图片或句子线索中**自己想出**英文，随后才能看答案。
- 选择题可用于刚学、连续失败或低信心时的脚手架，但“选对”只证明识别，不等同于能独立回忆。
- 答错后立即给正确答案和简短解释，并在本轮稍后再次要求独立回答。

边界：实验条件、材料和测试形式不同，不能据此断言某个具体 UI 或某一种题型对所有人最佳。完全没有初始编码时直接测试可能只会变成盲猜。

### 2. 间隔复习：强证据，但不存在通用固定间隔

Cepeda 等对 1,350 多名参与者进行了最长约一年的实验。合适间隔随预期保持时间变化：想保持越久，复习间隔通常也应越长；并不存在对所有目标都最优的固定“1、3、7、30 天”。[原始论文](https://doi.org/10.1111/j.1467-9280.2008.02209.x)，[作者 PDF](https://www.evullab.org/pdf/CepedaVulRohrerWixtedPashler-PS-2008.pdf)。专门针对日英词对的实验也发现，间隔的长期收益随练习次数和最终保持间隔而变化。[Pavlik & Anderson 原始论文记录](https://pubmed.ncbi.nlm.nih.gov/21702785/)，DOI：[10.1207/s15516709cog0000_14](https://doi.org/10.1207/s15516709cog0000_14)。

产品含义：

- 每个词必须拥有独立的到期时间和记忆强度，不能全体按同一日历刷新。
- 首页先处理到期复习；新词数量由剩余容量决定。
- 快速、独立答对后延长间隔；迟疑、借助提示或答错后缩短间隔。
- “每天 50 个”应解释为每日新词上限或总学习量目标，不能无视复习积压强行每天加入 50 个新词。

边界：研究支持“间隔应随目标和表现变化”，但不直接给出适合本用户的精确参数。精确间隔应由个人历史数据校准。

### 3. 生成与拼写：主动生成较可靠，机械抄写不可靠

经典生成效应实验中，参与者自己生成的词比直接阅读的词在多种记忆测试上表现更好。[Slamecka & Graf 原始论文](https://doi.org/10.1037/0278-7393.4.6.592)。但它不是专门的第二语言拼写研究，不能把“任何写字”都解释为生成效应。

第二语言研究提供了重要反例：Barcroft 让初学者在学习西班牙语名词时抄整个词、抄词片段或不抄；不抄条件的词汇学习成绩更高。另一项实验也发现，学习时机械抄词的即时和两天后产出成绩低于不抄。[原始论文 2007](https://doi.org/10.1111/j.1944-9720.2007.tb02889.x)，[原始论文 2006](https://doi.org/10.1191/0267658306sr276oa)。这说明无意义抄写可能占用初始编码资源。

产品含义：

- 拼写应是“从意义或声音中检索词形”，例如中文→英文、听音拼写、句子空格完整输入；不是照着答案抄三遍。
- 拼错后标出差异、显示正确形式，然后隐藏答案并稍后重测完整单词。
- 造句放在已建立基本词形—词义联系之后，不作为第一次接触的主要任务。

边界：不同抄写和输出研究的结果并不完全一致，任务、水平与测试指标都会改变结果。可以较有把握地说“主动检索通常比机械抄写更合适”，不能说所有手写都无效。

### 4. 语境阅读：适合巩固和迁移，不能单独承担记忆

Hulstijn、Hollander 与 Greidanus 让高级法语学习者阅读短篇小说。未知词出现三次而非一次时，只有在边注释义或词典帮助下，词汇学习收益才更明显；没有可靠释义时，学习者可能忽略或错误推断词义。[大学机构保存的原始论文](https://pure.uva.nl/ws/files/1979878/165032_Hulstijn_Hollander_Greidanus_1996.pdf)，DOI：[10.1111/j.1540-4781.1996.tb01614.x](https://doi.org/10.1111/j.1540-4781.1996.tb01614.x)。

Pellicer-Sánchez 的眼动实验中，L2 学习者在故事里遇到目标伪词八次后，词形识别约 86%、词义识别约 75%，但词义回忆约 55%；识别明显容易于主动回忆。[原始论文 PDF](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/791C52E20B00D64C4C2EC7CA7D735EC8/S0272263115000224a.pdf/incidental_l2_vocabulary_acquisition_from_and_while_reading.pdf)，DOI：[10.1017/S0272263115000224](https://doi.org/10.1017/S0272263115000224)。

不同语境的作用还可能随学习阶段变化。一项 239 名成人的实验发现，多样语境更有利于把词义推广到新语境，但并非所有词形和词义指标都同时受益。[原始开放论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC10280660/)，DOI：[10.1177/17470218221128732](https://doi.org/10.1177/17470218221128732)。

产品含义：

- 首次例句应短、提示性强并提供可信释义，避免让用户同时猜整句和新词。
- 后续复习逐步更换语境：高提示单句 → 新主题单句 → 段落或新闻 → 用户造句。
- 阅读中点开词义只记录为一次“接触”，不能标记为掌握；之后自动生成主动回忆题。
- 同一词不要永久绑定同一个例句，否则用户可能记住句面位置而不是学会迁移。

边界：不少研究使用伪词、人工文本或短期测试。语境阅读能帮助理解和迁移，但不能证明“每天读一篇新闻”本身足以形成可产出的词汇能力。

### 5. 难度自适应：原理有依据，具体参数必须个人化

Settles 与 Meeder 提出的 Half-Life Regression（HLR）用每个项目的历史表现估计记忆半衰期，并用 `p(recall) = 2^(-elapsed / halfLife)` 预测当前回忆概率。在 Duolingo 数据中，HLR 对回忆概率的预测误差低于多个基线；这是一套可追溯的个性化调度原型，而不是对所有学习者已经证明最优的最终算法。[ACL 原始论文与实现说明](https://aclanthology.org/P16-1174/)，DOI：[10.18653/v1/P16-1174](https://doi.org/10.18653/v1/P16-1174)。

产品含义：local-first PWA 可以在设备本地保存每词的稳定度、难度、上次复习时间和结果，用简单可解释的半衰期模型调度；无需云端模型。

边界：HLR 的参数由大规模平台数据训练。本项目单用户数据很少，不应照搬论文权重；先用保守默认值，再用个人记录逐步更新。

## 建议的本地学习状态机

```text
NEW
  -> ENCODING（读音 + 核心义 + 一条高提示例句）
  -> LEARNING（本轮内间隔后的意义回忆和词形回忆）
  -> REVIEW（跨天到期复习）
  -> CONSOLIDATING（能独立回忆，开始多语境、听写、完形）
  -> MATURE（长间隔保持；仍会按预测概率复习）

任意状态答错 -> LAPSED（立即反馈，本轮稍后重测，缩短间隔）
用户明确不学 -> SUSPENDED
```

建议每词本地字段：

```ts
type WordMemory = {
  state: "new" | "encoding" | "learning" | "review" | "consolidating" | "mature" | "lapsed" | "suspended";
  dueAt: string;
  stabilityDays: number;
  difficulty: number;
  lastReviewedAt?: string;
  reviews: number;
  lapses: number;
  consecutiveIndependentRecalls: number;
  lastResult?: "again" | "hard" | "good" | "easy";
  meaningRecallPassed: boolean;
  spellingRecallPassed: boolean;
  contextTransferPassed: boolean;
  averageResponseMs?: number;
};
```

一次学习的推荐流程：

1. **到期队列优先**：先做预计回忆概率最低、逾期最久的旧词。
2. **先回忆，后显示**：能独立输入时不先给选项；失败后再降级到首字母、选词或释义提示。
3. **反馈与重测**：答错立即纠正，并插入本轮后部重测；只有后一次独立答对才离开 `lapsed`。
4. **有限的新词编码**：看清读音、核心义和一条例句；隔开 1–3 个其他项目后第一次回忆，本轮至少两次独立成功才进入跨天复习。
5. **题型随状态升级**：初学用意义回忆；随后加入中文/听音→英文拼写；巩固期加入新句子完形和短文定位。
6. **预测到期时间**：根据本词稳定度估计回忆概率，在它跌到目标阈值附近时安排复习；具体阈值由个人数据调整。

## 每日新词与复习比例

没有找到能证明固定 `新词:复习 = 1:4`、`20:80` 或其他比例对所有学习者最优的一手证据。固定比例不应被包装成科学结论。

建议采用容量约束，而不是比例约束：

```text
今日时间预算
  -> 先安排到期和逾期复习
  -> 估算剩余时间
  -> 再加入不会明显增加未来积压的新词
```

可作为产品初始默认值、但必须明确属于**待校准的工程规则**：

- 最近 7 天独立回忆正确率低或逾期队列持续增长：暂停新词。
- 表现一般：降低新词上限，优先消化旧词。
- 到期队列稳定、独立回忆表现稳定：逐步恢复用户设定的新词上限。
- 用户的“每天 50 个”可拆成“最多 50 个学习项目”或“最多 50 个新词”，并明确显示预计复习负担。

不应直接写死 75%、85% 等阈值并声称来自研究；这些阈值需通过本人的一周后保持率、反应时间、积压变化和主观负担逐步校准。

## 建议的首版改造优先级

1. 把每日入口改成“到期复习优先”，并为每个词保存独立状态。
2. 将翻卡改为“先输入/口头回忆，再看答案”；选择题仅做提示或低阶检查。
3. 增加答错后的本轮重测与跨天缩短间隔。
4. 将拼写改成检索式拼写，取消机械抄写作为主任务。
5. 阅读点击词加入待学习队列，并在之后用新语境主动测试。
6. 收集个人保持率与负担数据后，再调半衰期和每日新词上限。

## 最终证据判断

- **强，建议直接采用**：主动回忆优先于重复观看；跨时间分散复习；按项目表现调整复习；答错后提供正确反馈。
- **中等，适合组合使用**：从意义/声音生成拼写；多语境阅读用于巩固和迁移；识别题作为脚手架。
- **因人和阶段而异**：最佳间隔、每天新词量、难度阈值、题型比例、造句出现的时机。
- **不应声称有效**：统一固定间隔对所有词适用；固定新词/复习比例是科学最优；翻卡熟悉感等于掌握；机械抄写必然有效；仅靠每日阅读即可稳定产出词汇。
